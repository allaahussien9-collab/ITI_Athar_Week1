
# Weather Information App

ITI ATHAR Initiative - Week 1 Task

## Project Description
A Python application that retrieves weather data
from a public REST API and displays a formatted report.

## Features
- Fetch weather data using REST API
- Parse JSON responses
- Store data using a Python class
- Display temperature and humidity
- Use environment variables for configuration

## Technologies
- Python
- Requests
- python-dotenv
- Open-Meteo API

## How to Run
1. Create a virtual environment.
2. Install packages from requirements.txt.
3. Create a .env file with the required settings.
4. Run main.py.
